# First irregular Glitter browser checkpoint

23 September 2026. The main XF Studio editor now exposes an explicit **Try irregular glitter** action for a Glitter layer. It saves `irregular-planar-1` settings in `xfs/recipe-7`; v1–v6 recipes retain their existing cell-flake appearance and mask bytes. The game compiler continues to reject Glitter. No third-party photograph or game asset enters the product bundle.

The candidate uses the project-authored polygon field from Experiment 007 at its four-sample setting. A single cancellable raster worker constructs its catalogue in slices, bakes mask and optical maps, extracts compact one-channel coverage and alpha caches, and composes a linear-light RGB mixture with exact shape alpha. It publishes only a complete latest-version bundle. Normal and surface maps are reused across base/flake colour edits when their optical key is unchanged; a shape edit uses cached field coverage. The receiving stack binds an sRGB RGBA albedo at white material colour and keeps the prior complete material while a replacement is pending. Switching finishes, disabling, replacing, or removing a layer disposes candidate resources. The ordinary mask remains authoritative for UV editing and PNG export.

The operational budget counts four RGBA maps per enabled candidate, its largest replacement bundle, worker outputs and scratch, a 64 MiB compact cache allowance and a conservative 128 MiB catalogue/index allowance. The current fixed 1 GiB guard admits a single 2K candidate and rejects 4K. Quality changes release the old maps before the new tier starts. This is an allocation guard, not a report of free GPU memory. Ordinary mip filtering loses subpixel normal variance; four-sample coverage can appear quantized. No lighting, view-distance or game-parity claim follows from deterministic map tests.

Validation in the isolated worktree: typecheck and browser bundle build passed; the full suite covers frozen legacy flake hashes, old SQLite revision retention, strict schema-7 rejection, candidate alpha/colour/cache and cancellation behavior, material disposal and the compiler rejection. Ignored local preview GLBs were linked from HQ for asset-dependent tests, and remain ignored. An alternate-port `?verify=1` server served the editor and both bundles successfully. A visual browser comparison against reference photographs and runtime game evidence remain open.
