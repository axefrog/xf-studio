# Holotable: the live world view

Research for Holotable, a private, game-external and in-game view of what the game and XF's own systems believe is happening in the world right now. It is built as a typed, time-indexed model of the world with layers from several producers (the runtime bridge, offline world data, the Story Engine), and every surface is a projection of that model: a translucent in-game overlay, its CET settings window, an optional external window, agent-readable reports and stills.
