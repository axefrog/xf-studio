The ZIP entries were checked for traversal, rooted names, backslashes and case-insensitive duplicate paths. Complete package contents, including license/notices and companion Bundle/Data/Scripts files, were extracted to a private ignored stage and copied into **new** MO2 mod folders; source and copied file hashes matched before each folder was published. No old framework folder was overwritten. Only the diagnostic profile's modlist changed: `ArchiveXL`, `TweakXL` and `Codeware` were disabled, and the three versioned entries were enabled. The new modlist SHA-256 is `3b63b84fe9fcecbae282a1aef5a9c9f86b55578ca7ff3eb79e7424bea3e538ef`. Its earlier exact bytes remain in the ignored private stage for recovery.

A physical-file scan of the enabled diagnostic entries found exactly one candidate for each `red4ext/plugins/{ArchiveXL,TweakXL,Codeware}` DLL path, supplied by the corresponding new folder. That is **not** proof of the effective MO2 virtual winner or actual game-loaded version. Before launch, confirm these winners in MO2 and capture fresh RED4ext, framework and redscript logs. The physical game-root RED4ext loader is still 1.30.0 and was not changed; a loader upgrade would affect other profiles without a separate isolation method. The [official MO2 Cyberpunk plugin source](https://github.com/ModOrganizer2/modorganizer-basic_games/blob/master/games/game_cyberpunk2077.py), inspected 25 September, motivated treating root-loader deployment differently from ordinary profile-selected framework mod files. Its branch link was not pinned to a commit for this checkpoint.

ArchiveXL and Codeware tagged notes name game 2.31; the [TweakXL 1.11.4 tagged README](https://raw.githubusercontent.com/psiberx/cp2077-tweak-xl/v1.11.4/README.md) still names 2.3. Do not turn that documentation gap into a compatibility claim. The first controlled runtime session must record actual loaded versions, script compilation and selector behavior. The baseline can be restored by selecting the unchanged original profile; if the diagnostic profile itself needs rollback, reverse only its six framework toggles from the private before-image. Do not delete versioned folders or force the package-promotion rollback after the profile was deliberately edited.
