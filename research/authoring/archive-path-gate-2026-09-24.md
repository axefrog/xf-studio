# Generated archive path gate — 24 September 2026

The local package builder now checks the generated resource tree immediately before `pack`. The expected set comes from the filtered collection plan: mesh, morph, app, customization and exactly three XBM paths per retained preset. Every generated file must have a lowercase, slash-separated relative depot path made from archive-safe ASCII characters, an expected extension and no traversal or alias segments. The gate also rejects symlinks, extra/missing files and duplicate 64-bit depot hashes. It records sorted path, size, SHA-256 and decimal 64-bit path hash entries in the private `build.json`. The separate verifier recreates this inventory and requires the unpacked archive's path set and bytes to match it.

This rule follows the local WolvenKit source at `11720772f1e20581301b3dec88a59f7b5ee05675`: `WolvenKit.Core/Services/FilepathValidationTools.cs` documents archive-safe characters; `WolvenKit.RED4/Types/Primitives/Simples/ResourcePath.cs` lowercases, normalizes separators and collapses repeats; `WolvenKit.RED4/Archive/IO/ArchiveWriter.cs` skips unsupported extensions, hashes sanitized paths, accepts a decimal-leading hash override and aborts duplicate path hashes. The project accepts only its canonical generated subset before packing, so a silently rewritten or omitted path cannot count as planned output. This checks packaging semantics; it does not verify ArchiveXL execution or game rendering. [WolvenKit credit](../../docs/community-credits.md#WolvenKit--the-WolvenKit-team-and-contributors).

The focused Python tests passed five cases, including WolvenKit's own `base\characters\head.mesh` hash vector (`8995421073019654957`), canonicalization rejects, missing/extra inventory, content-digest changes and a forced hash collision. The Studio package CLI's four preflight/partial-export tests passed unchanged. A fresh four-preset wrapper build with the existing local CLI 8.17.4 and private source plate passed the independent verifier: 16 unpacked resources, 12 textures, five selector choices including Off, 105 morphs and unchanged model buffers. Its 16 `(depot path, SHA-256)` pairs exactly matched an earlier local build of the same fixture. The packed archive SHA-256 was `78300ee3a8b700b38e9d6e8fe32e65f3ee0696b2603694e5239a9d06a130432c` and its size was 847,872 bytes; index timestamps can change that hash between rebuilds. The path gate is a package-content boundary. A later approved MO2 or direct-game transport can use the same verified candidate and manifest without changing resource naming or compiler bytes. That installation design and runtime proof are separate work.
