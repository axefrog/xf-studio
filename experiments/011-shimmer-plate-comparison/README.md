# Shimmer on-plate comparison candidate

**Status:** awaiting runtime session — a private six-choice Shimmer selector package on the owned plate verifies offline (19/19 resources byte-identical after unpacking), but it has not been staged, installed or tested in game. It is not part of the first smoke test, which covers Matte and Metallic with Satin optional ([runtime preflight card](../../research/authoring/first-makeup-runtime-preflight-2026-09-25.md)).

24 September 2026. This is a **private, uninstalled diagnostic package**, separate from the Studio's production exporter. It binds a real Studio Shimmer recipe's exact mask, pigment, legacy optical normal and roughness/metalness maps to the owned morph-skinned eye plate in one character-creator selector. The six choices are Off; a flat-normal control; and a 2 × 2 test of tangent normal green sign and `NormalsBlendingMode` 0/1. Normal mode and sign are the only differences among the four active optical choices. All five active choices reference the same diffuse, independent normal-coverage, roughness and metalness XBMs. The flat choice uses the same maps but disables normal contribution.

The build deliberately duplicates the plate mesh and morph resource for each active choice so each can carry an explicit material instance. This is a controlled, source-grounded comparison architecture, **not** the production packaging plan or an optimized release. Each selector definition directly names an app appearance with its own `entMorphTargetSkinnedMeshComponent`; Off has no component. The candidate's ArchiveXL declaration registers the one female selector and app scope. Whether the installed game/ArchiveXL actually presents these choices, clears one when switching to Off, and shades either normal mode as anticipated remains unobserved.

## Reproduce privately

Run from the HQ root, passing the imported plate and the exact locally extracted game template if the documented defaults are not present:

```powershell
python experiments/011-shimmer-plate-comparison/build.py --plate D:/Dev/cp2077-modding-hq/experiments/004-plate-import/generated/archive/axefrog/appearance_studio/studies
python experiments/011-shimmer-plate-comparison/verify.py
```

The default source is the same sample as [Experiment 010](../010-shimmer-game-adapter/README.md). A portable real recipe can be supplied with `--recipe <path> --layer <id>`; the selected layer must be enabled, Shimmer, positive-opacity and legacy `cells` optics. `--size` is a power-of-two 256–2048. The underlying scaffold invokes Experiment 005 on a temporary **package-only flat surrogate** of that exact contour, because its production compiler intentionally rejects Shimmer. That surrogate is discarded from the final archive; the candidate's seven textures come from the original Shimmer raster and optical bake. The generated candidate, converted game resources and logs remain ignored. The scripts never copy into the game or mod manager and never change the production Shimmer guard.

The builder requires the SHA-256-pinned Cyberpunk 2077 2.31 `mesh_decal.mt` (`b1b181b70fd1b16393d626281eeff1d5fc99932f24868e55248d18a1abfbc019`) and its serialized JSON with `MVF_MeshSkinned`, the required parameter names and a white default `NormalsBlendingModeAlpha` texture. That default leaves the mode-1 interpolation fully selected; the diagnostic does not add a separate map for it. This exact template, the owned plate resources, WolvenKit CLI 8.17.4, Bun, Pillow and the local game path are private prerequisites. The script does not track or redistribute them.

## Offline evidence and limits

The independent verifier reads **round-tripped** mesh, morph, app, customization and XBM resources, then unbundles the archive and checks every binary hash. It checks one selector, six indexed options with Off at zero, distinct compiled components, five resolved mesh/morph paths, xfs-prefixed generated resource names, all local texture references, and unchanged source mesh render/bone buffers and morph blob/105 targets in *every* variant. Thus the native skin and embedded morph base bytes survive conversion by comparison with the source-resource JSON, within the serialized fields checked. The verifier also checks source-map channel provenance, green inversion, flat normal, material scalar values, every decoded mip chain's dimensions/format, and masking outside the source shape. At the measured base level, the decoded normal-coverage map is exactly zero outside the source mask. The decoded diffuse alpha is at most one byte outside it; squared shader coverage from that byte is tiny but not mathematically zero. Bilinear/trilinear filtering and mip edges can still spread coverage.

These facts establish an internally consistent **static candidate**, not ArchiveXL execution, game-material behavior, appearance fidelity or save stability. The stock shader's single blended PBR surface differs from the browser's separate transparent Shimmer layer. Small normal slopes disappear in lower mips, as quantified in Experiment 010; this comparison alone will not cure that. The current plate also retains the known eyelid-contact limitation. The production compiler/export filter still omits active Shimmer.

The checked sample's recipe SHA-256 is `e26c7ec7e2455ba804fb1941c3a4079f0fbabf37eace194ebd3d66697dbd91f8`; exact shape/normal/surface byte hashes match Experiment 010's [record](../010-shimmer-game-adapter/result.json). The private plate inputs were mesh `9099726e9842888232ae22c0abf41a6b9fb99c6bf44f36c7786fe0d791223fed` and morph `7252eaad86f58e31c54c6168a30b3eb34a3e22e2edbb55d6ef826b310eaf6b4b`. The template-checked build unpacked **19/19** resources byte-identically: seven shared XBMs, five mesh/morph pairs, one app and one customization resource. Source square-root coverage alpha differs from the intended shape by 0.00133 mean on partially covered texels. At 1024² the decoded normal-alpha is zero at every source-off texel; colour compression leaves alpha byte 1 at 56 of 1,037,080 source-off texels (all others zero). The local `.archive` SHA-256 for this run is `98bb9a1efa44c149677c5924ab7e5310b545c322398e9f6bd6313fb95c9b77a5`; archive container timestamps can change that hash on rebuild, so compare unpacked resources as well. Full mip hashes and paths are retained only in ignored `generated/candidate-template-checked/verification.json`.

Decoded XBM channel tiers reproduce the material-only warning: ≥0.15 tangent slopes occupy 16.0% of covered texels at 1024, 7.4% at 512 and zero at 256 or smaller. Roughness and metalness means remain roughly 109 and 28 bytes over the same covered tiers. This is source-map filtering evidence, not a judgment of visible shimmer at those projected sizes.
