# Session 2: one in-game session for depth, gloss, shimmer and texture placement

**Status:** built through the production pipeline, independently verified, staged in the test MO2 profile (`XF Studio diagnostic 2026-09-25`, mod **XF Eye Artistry**). Not yet seen in game.

This is an asset-free diagnostic collection, [`session-2.collection.json`](session-2.collection.json), generated by [`make-session.ts`](make-session.ts). It combines two experiments so that one session answers both:

- [Experiment 017](../017-plate-depth/README.md): the plate lift that fixes close-up breakup, the Matte/Satin gloss calibration, a stronger Shimmer and the lifted metal ramp.
- [Experiment 019](../019-uv-window/README.md): the plate-local UV window that gives exported makeup about 4× the linear texture density. The placement pair is the only 019 check that must pass before the new density is trusted.

With the UV window now the default, the 017 presets here are built at the new density; only **Lines · old** uses the old head-UV layout.

## Test card

Use MO2 profile **XF Studio diagnostic 2026-09-25**. Load a save, make a new manual save first (this profile shares the save folder), then use a mirror's appearance screen to pick presets and photo mode to look at them. Load the safety save afterwards to restore the usual look.

1. **Selector.** The **XF** row lists Off plus 12 presets, and every name fits.
2. **Placement first.** Switch between **Lines · new** and **Lines · old** at a fixed photo-mode camera. They must sit in exactly the same place; the new one should just be sharper close up. If they don't line up, stop and send that screenshot: nothing else at the new density can be trusted.
3. **Depth A → D.** Photo mode with the eyes filling the frame: one screenshot each. Which is the smallest lift that stays solid? On D, check the inner eye corners at the lash line for skin showing through.
4. **Depth D in motion.** Pull back to normal framing, then watch a blink and a slow head turn. Look for a visible edge or a lifted look.
5. **Gloss A–D.** Same framing and light for each, then a light sweep. Which reads most like four distinct finishes? A and B looking alike would mean the written roughness isn't what you see; C still glossy would mean the shine comes from lights or reflections.
6. **Shimmer · strong.** Close up, do points flash as the light moves? At face distance, does it still look different from Satin?
7. **Metal ramp · lifted.** Are the angular highlight shapes gone, and is there a visible seam partway along the lid?
8. Note whether ray tracing or path tracing is on, and the game version.
9. **Optional: piercings and the heart eye.** While at the mirror, set XF to Off, then one close-up each under the same light: piercing style 9 in black, style 1 in silver, then gold, and eye colour 24 (the heart design). The Studio now draws these from the game's own layered materials; a gold that shows grey, or plastic without its colour, tells us which way the game reads their colour mask ([test ask 14](../../knowledge/head-cc-rendering.md)). Restore your usual piercings and eyes afterwards (or load the safety save).

Send the screenshots with a short note per step.
