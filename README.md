# Cyberpunk 2077 Modding HQ

Home for clean mod implementations, focused experiments and source-grounded research. XF Appearance Studio comes first; Photo Mode Tools is the second independent project.

Source repository: [axefrog/xf-studio](https://github.com/axefrog/xf-studio). The repository preserves this HQ layout so research and reproducible experiments accompany the implementation. Machine-specific inventories, credentials, saved games, SQLite libraries, extracted assets and the game-derived Blender master remain local. Links into those excluded folders work in the original workspace only. A clone supplies source and research, not a ready-to-run bundle of Cyberpunk assets; see the [authoring setup](projects/xf-appearance-studio/authoring/README.md).
