Knowledge base

How Cyberpunk 2077 fits together, as far as we know

XF Studio runs a research lab beside the product. It studies how the game’s engine, resources and modding frameworks work, so that the Studio can read game files the way the game does. These pages share its consolidated findings with the modding community. They are generated from the knowledge base in the repository each time the site is built, so they follow its current state.

02Corrections

Help us get it right

These notes will contain mistakes. If you know better, or can confirm something in game, please open an issue or send a pull request that edits the page’s Markdown in the knowledge folder. Links to sources, captures or tests help most.

The Cyberpunk 2077 Modding Wiki remains the community’s reference. These pages link to it rather than copy it, and add what our own reading of source code and resources found.
