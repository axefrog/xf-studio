# Legacy modules

`legacy/eye-makeup/` holds eye makeup's modules that the shell still reaches: its model, descriptors, Undo labels, history part, authoring port and recipe lineage, the layered preview's policy and devices, the UV and on-head editors, the package pipeline and the expanded eye plate. They belong to `features/eye-makeup/`, but the composition rule (CORE-29) keeps a module out of a feature folder while anything outside the composition imports it, so they wait here on the feature-module platform's remaining steps ([CORE-03 steps 8–9](../../../../../research/authoring/feature-module-platform.md#8-migration-plan)). Each moves into the feature when its last outside importer goes. Nothing new goes here: new eye-makeup code belongs in `features/eye-makeup/` or an engine.
