3. **`src/resolve.ts`**: the core (spec §5). Design decisions already taken:
   - `Resolver.resolve(node, path, t)` makes an outer operation: one `Allowance` (config.allowance), a stack of (node, slot) for the cycle guard (re-entry returns `cycle` and records a defect), depth limit 32, 256 applicable contributions, 64 field points, N_enum. `LimitExceeded` is caught at the outer boundary and returned as `failed` plus a defect. Nested resolutions share the allowance. Engine cache keyed `node|slotKey|t`, valid for one revision only; mirror results into `Node.slots` (`open`/`resolved`).
   - Effective mode: node origin `mirrored` and slot `mirrored` gives mirrored; else slot with `derive` gives derived; else a `vec`/`text` dim gives assigned; else the declared mode. `node`-dim slots are structural (the Id by formula, always `ok`).
   - Constraints for (node, slot, t): pins in effect (valid `[from,to)`, not withdrawn; precedence by reason 600/500/400/300); `constrain` contributions whose selector matches (kind via ancestors, slot or `*` or `key[*]`, scope, where) and valid at `t`; view preimages from same-node derived slots with one input equal to this slot, chained (the constraint keeps its source Id and precedence); structural constraints at 700 (`count >= i+1` for the highest retained member of that `many` slot, via a revision-cached mark pass; summary `count >= max(canon)+1`). Sort by precedence desc then Id.
   - Arbitration is symbolic on `Region`s: start with the domain (enum-by: the list chosen by the resolved `by` slot), intersect in order, reject on empty, status `contradiction` iff a rejected constraint has precedence >= 600. Enumerate F only for the draw (cost |F| units; > N_enum gives `failed`).
   - Weights and draw exactly as spec 5.3/5.4: normalise each factor by its max over F, `score = ln P0hat + sum strength*ln fhat` in contribution Id order starting from the prior term, `g = -ln(-ln(rand("g", worldSeed, node.id, slotPath, k, v)))` using `fdlibm-log.ts`, argmax of `score + g`, exact ties to the lower `H("tie", worldSeed, node.id, slotPath, k, v)`. Hash arg for `v` is `val(encodeValue(vt, v))`. `k` is the window index (0 if not temporal). Forms: const (set in constrain mode; 1 on v and epsilon elsewhere in weight mode), set, table, field (positions via `base` slot, falloffs linear / smoothstep `1-3x^2+2x^3` / bump `(1-x^2)^2`, combine sum or max, then a `fieldmap` fn), rule(when, then), derive (as `Const(derive(inputs))` in constrain mode). First `replace-prior` contribution in precedence order replaces the prior.
   - Assigned: arbitration with value pins and constraints; if F is a single value, that is the value; else `unavailable` (SPEC-NOTES 6). Summary items get `time`/`place`/`kind` defaults from their descriptors when the arbitration allows (see 8).
   - Mirrored on a mirrored node: the reading in effect at `t` (a `game` pin; readings ordered by time then Id, the last wins; each reading's `valid.to` is the next reading's time, recomputed on insert); none gives `unavailable`; status `contradiction` if an active pin of precedence >= 600 disagrees with the reading.
   - Derived: resolve inputs, `derive.fn`, then the pin check per SPEC-NOTES 7. Status severity: failed > cycle > unavailable > contradiction > ok; derived slots inherit the worst input status, sampled slots inherit only failed/cycle/unavailable.
   - Paths: segments split by `/`; `^` is the owner; slot segments cross node slots; `key[i]` addresses member i (needs `count > i`); owner-chain reads in derive inputs are `^/key`. Id formulas are in `id.ts`. `Kernel.address(owner, path)` creates headers lazily and silently (no revision bump, no change).
   - `ref` sampled slots: candidate set = the query (limit all) cut to the `max` lowest Ids; empty gives `unavailable`; a hit limit gives `failed`.
   - `trace(node, path, t)` re-runs resolution with a collector (bypassing the cache): every constraint with active/rejected, |F|, every weight contribution with its normalised factor at the winner, the prior, winner score and noise, runner-up (second by `score+g`), plus all candidates. `explain` per SPEC-NOTES 28.
