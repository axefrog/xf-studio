# Branches left uncovered on purpose

`bun tools/coverage.ts` counts every branch outcome of the engine (if and ternary tests both ways, the right side of `&&`, `||` and `??` taken and skipped, switch cases, default parameters) over the test suite and the conformance vectors. The outcomes below are never reached, and are kept anyway, for the reason given: each guards a state the rest of the engine already rules out, and removing it would make that state's consequences worse (a crash or a silent corruption instead of nothing), not the engine smaller. Line numbers drift; the function and the condition identify each one. Anything uncovered that isn't listed here is a missing test.

| Where | Outcome never reached | Why it can't be reached |
|---|---|---|
| `kernel.ts` `drain` | a primed set with no active node | a node is primed only while active, and going dormant takes it out of the set |
| `kernel.ts` `dropFollower`, `disconnect`, `forgetProcess` | the node already forgotten, not in its scope's list, already inactive; a process without a parent or not among its children | each is forgotten or disconnected exactly once: a process only once it is terminal (its terminal flag stops a second end), a follower only with its edge, an effect only while connected |
| `operators.ts` `scan`, `flatMap` | an error among an input's fresh entries; an error on the inner node | the input-error guard before them returns any input's error first |
| `model.ts` `references` walk, `followsOf`, `derive` | a leaf that isn't a reference under a reference field; a derivation cycle without its nodes | only fields whose leaves are references are walked; a cycle result always carries its cycle |
| `resolve.ts` `candidateKeys` | a node whose state exists but whose type isn't registered, or a leaf path asked for its map keys | callers reach it only through `mapKeys` of a map path of a registered type |
| `store.ts` `listNow` | a stream without entries | a stream is created by its first entry and removed with its last |
| `trust.ts` `resolveClaims` | two latest claims of one actor | claims are reduced to one latest per actor before ranking |
| `graph.ts` sorts (`set.nodes`, `sorted`, `inspect`, `diffLeaves`) | two different items comparing equal | the keys sorted are node IDs, conflict IDs or path keys, distinct by construction |
| `graph.ts` `headState`, `metaOf`, `referrers`, `modelAt`, `pinnedModel`, `load`, `emit`, `refresh`, `onReply`, `repositionPending`, `recover` | a record missing, of another type, or with no head where the caller just found or created it; an unpinned layer asked for its pinned point; a type that isn't registered | records are looked up by IDs taken from the records, the indexes or the outbox, which change together; records of unregistered types are never made |
| `graph.ts` `Working` (`state`, `push`, `drop`), `build`, `buildEdit`, `buildCreate`, `buildClone`, `checkLayers`, `target` | a working state that is retracted or of another type, an edit dropped that wasn't recorded, a clone target already mapped or taken, optional edit members missing where the edit form always supplies them | the edit is validated before these run (`editable`, `target`), and a clone maps each source once |
| `graph.ts` `restoreRecords`, `applyWork` | a rollback of a commit to a node that no longer has a record, or a check that returns nothing then finds no new blocking conflict | a refused fix restores exactly what `saveRecords` took just before; the `check` hook is only `fix`'s |
| `graph.ts` `pump`, `scheduleRetry`, `whenSettled`, `storeTask`, `writeSnapshot`, `snapshotAll`, `loadHistory`, `sync`, `compact`, `collapseInline`, `purgeInlined` | store work asked of a graph without a store, a second retry or append while one runs, a second settlement, a snapshot of a node that no longer folds, a sync with changes but no foreign entry, a compaction with nothing acknowledged after flushing, an inlined node with pinned dependents | each caller checks the store (or runs only with one) first; the outbox keeps one append and one retry in flight; a flushed stream's entries are acknowledged; a node referenced by a pin can't be collapsed inline, since an entry referencing its entries refuses the collapse |
| `graph.ts` `compensate` | a step whose record or node is gone, or that restores a retraction | undo stacks drop the steps of purged nodes; the only retraction a step makes is undoing a creation, which compensates by `retract`, never by restoring one |
| `graph.ts` `followsClosure`, `subscribe`, `indexRefs`, `depthOf`, `inspectNode`, `onCycle`, `trimRing` | a follow edge already seen or not following, a subscription whose inputs are unchanged, an index row emptied twice, a layer cycle in the inspector's depth, a dependent without a record, more than 64 change sets assembled in one cycle, a source ring without its size | the closure marks each node once; layer cycles are refused on commit; change sets are taken as soon as their cycle ends; a source's ring size is recorded when its stream is made |
| `graph.ts` `emit` | the change set made up without its cycle (and its label) | every commit, undo, fix, recovery, sync and purge runs its cycle at once (commits during a cycle are refused), which assembles the change set |
| `graph.ts` `refresh` | conflicts indexed without the reference index | the conflict index builds the reference index first |
